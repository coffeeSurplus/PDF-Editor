# PDF Editor

## Summary

PDF Editor - view and edit PDF documents

* Home - edit PDF documents, pin folders and files
* Browse - browse and search for files in Documents, Desktop, Downloads, or any other location
* View - view PDF documents

## Home

![Home](/Gallery/Home.png)

**Features**

* Tools - Merge PDF, Split PDF, Extract pages, Remove pages, Reorder pages, Rotate pages, Edit properties
* Pinned folders and files

## PDF tools

![Merge PDF](/Gallery/MergePDF.png)

![Extract pages](/Gallery/ExtractPages.png)

![Edit properties](/Gallery/EditProperties.png)

**Features**

* Merge PDF - merge multiple PDF documents into one
* Split PDF - split a PDF document by either every page, every n pages, or after certain pages
* Extract pages - extract selected pages from a PDF document and either save as one file or save as individual files
* Remove pages - remove selected pages from a PDF document
* Reorder pages - reorder pages in a PDF document
* Rotate pages - rotate all, selected, or single pages in a PDF document
* Edit properties - edit Title, Author, Creator, Keywords, and Subject on a PDF document

## Browse

![Documents](/Gallery/Documents.png)

![Documents search](/Gallery/DocumentsSearch.png)

**Features**

* Browse folders in Documents, Desktop, or Downloads
* Open PDF documents
* Browse PDF documents via native file open dialog
* Search for folders and PDF documents
* Open folders and PDF documents in Explorer
* Copy folder and file paths
* Pin folders and files to the Home page

## View

![View](/Gallery/View.png)

**Features**

* View PDF documents
* View by either single page, two pages, or two pages with separate cover page
* Fit to height/width
* Zoom in/out (between 10 and 800 %)
* Navigate pages
* Find text in PDF documents, with match case and match whole word options
* View and navigate contents
* View and navigate thumbnails
* View document information (file and document properties)

## 'Where exe'

I've uploaded the application as an executeable file to the releases section - there are two versions:
- PDFEditorLarge - self-contained .exe file, ~176 Mb in size; does not require additional installations
- PDFEditorSmall - framework-dependent .exe file, ~22.5 Mb in size; requires [net8.0](https://dotnet.microsoft.com/en-us/download/dotnet/8.0) to be installed
